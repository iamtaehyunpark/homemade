Coding agents make it five minutes to build a script. Six months later it is a forgotten folder with flags you no longer remember. Homemade is the launcher and runtime workspace where those programs live: an interface, a lifecycle, a window, and an agent that can run them for you.

Every script becomes an app

Drop a folder or a single Python file on the sidebar. Homemade reads the entry point, infers the inputs, and writes a small homemade.toml. From then on the program has a form, a Run button, presets, live logs, an output shelf, and run history.

interface

Forms, presets, outputs

Declared inputs become a form. Files the program writes show up in an output shelf. Progress lines render as a progress bar. Or ship your own HTML frontend through window.homemade.

lifecycle

Clean start, clean stop

Programs run as native processes with full machine access. Stopping a run ends the whole process group. Closing Homemade warns about live jobs and reaps orphans next launch.

windows

Solo windows and Launch

Open any program in its own window with nothing else around it, or pick it from the Launch grid. Close the window and the program exits cleanly.

workspaces

One workspace per program

Each program has its own tab group: the program panel plus as many shells as you want (⌘T). Switch between programs from the sidebar; the others keep running.

storage

Shared environments

Virtualenvs are deduplicated across projects, so PyTorch is on disk once instead of thirty times. Removing a program can take its scratch files and venv with it.

resources

GPU-aware queue

Programs can declare VRAM needs. Homemade queues jobs that would not fit, and the Monitor page shows CPU, RAM, and GPU headroom over time.

Built for coding agents

The agent that wrote your program should be able to run it, read its logs, and fix it, without you clicking Run. Every shell and agent session Homemade opens has the launcher on PATH and the MCP server connected.

# from any shell Homemade opened, or any agent
homemade run thumbnailer size=512 --wait
homemade log 3f2a91 --follow
homemade activity thumbnailer
homemade top thumbnailer      # resources of the live run
homemade capture thumbnailer  # screenshot of its window
homemade new my-tool          # blank project in ~/homemade

# MCP: same operations as tools
claude mcp add homemade -- \
  /Applications/Homemade.app/Contents/MacOS/homemade --mcp

Status, forwarded on your terms

When a run starts, finishes, or gets a failure diagnosis, the agent's terminal shows a one-line notice with a Send button. Nothing is typed into the session unless you choose to.

Point at anything in the program

Select mode is a devtools-style cursor inside the program's own UI. Click an element and a reference with its selector, text, and React or Vue component lands in the agent session, ready for "make this blue".

Managed CLAUDE.md and AGENTS.md

Registered folders get a short managed block so an agent started by hand in that folder still knows the app id, manifest, CLI, and MCP server.

Install

macOS on Apple Silicon today. One download, nothing else to install: the app bundles everything it needs. Linux builds are untested.

Download Homemade 0.1.0 (.dmg, 6 MB) .app as zip All releases

The build is not notarized yet, so macOS will block the first launch. Right-click Homemade.app and choose Open, or run xattr -dr com.apple.quarantine /Applications/Homemade.app once.

# or build from source
git clone https://github.com/iamtaehyunpark/homemade
cd homemade
pnpm install
pnpm tauri build
open src-tauri/target/release/bundle/macos/Homemade.app
  1. Add a program. Drag a folder or a .py file onto the sidebar, or use Add → Auto-import folder to let the local model draft the manifest.
  2. Run it. Fill the form, press Run, watch logs and outputs. Save a preset for next time.
  3. Hand it to an agent. Edit with Agent opens a shell in the folder with homemade and the MCP server ready. Start claude, codex, or agy from there.
  4. Make it feel like an app. Put an icon.png in the folder, open it from Launch, or set default_layout = "window".
